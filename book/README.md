## About This Book

This book covers all aspects of the Rolang programming language — from running your first program to building multi-package projects. Each chapter builds on the previous one, though individual chapters can also be read as standalone references.

Code samples in this book are real Rolang programs. Examples that return a value from `main` use the exit code as their observable output, which makes them easy to verify.
